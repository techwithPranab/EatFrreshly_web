## 🚀 Quick Start (3 Steps)

### Step 1: Get Your IDs (20 min)
1. Create GA4: https://analytics.google.com
2. Create GTM: https://tagmanager.google.com
3. Copy both IDs

### Step 2: Configure (2 min)
```bash
cd frontend
cp .env.local.example .env.local
# Edit .env.local and add your IDs
```

### Step 3: Test (5 min)
```bash
npm run dev
# Check console for 📊 messages
# Check GA4 Realtime for events
```

**Total Time: ~30 minutes** ⏱️
